Config files for hyperparameter optimization using `tune_autospeed_optuna.py`.

In the guide and blogpost, only `experiment1.yaml` is used (HPO over 7 hyperparameters), but we also provide two other examples:
* `experiment2.yaml`: a more limited HPO over just the loss component weights;
* `all_params.yaml`: HPO over all parameters – probably not desirable in practice.
